# ITensorMPSExtended.jl

Personal extensions to [ITensorMPS.jl](https://github.com/ITensor/ITensorMPS.jl) for research use.

## Installation

This package is not registered. From the Julia REPL:

```julia
using Pkg
Pkg.develop(path="path/to/ITensorMPSExtended.jl")
```

## Usage

```julia
using ITensorMPSExtended
```
